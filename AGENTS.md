# Agents

If you are a coding agent picking up this repository, the instructions are in
[`CLAUDE.md`](CLAUDE.md) — they apply to every agent, not only Claude. Then read, in order:

1. [`docs/HANDOVER.md`](docs/HANDOVER.md) — the current state, what is in flight, what to do next.
2. [`docs/WORKLOG.md`](docs/WORKLOG.md) — the phase plan and the open decisions.

Before changing anything, run `git status -sb` and `npm run check`.
